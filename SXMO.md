# SXMO на Poco F1 (Mobian forky): шпаргалка

Установлено `sxmo-utils 1.12.0-7` (Debian). Phosh остаётся по умолчанию; SXMO запускается вручную.
Настройка: `scripts/sxmo-setup`. Подробности и история — `STATE.md` п. 38–40.

## Запуск и откат

```sh
# запустить SXMO (останавливает Phosh; после ребута вернётся Phosh):
sudo systemctl stop greetd && sudo systemctl start sxmo
# вернуть Phosh без перезагрузки:
sudo systemctl stop sxmo && sudo systemctl start greetd
```
Что стартует на загрузке (сейчас SXMO) переключает `scripts/sxmo-default` (на телефоне от root; вступает в силу после ребута):
```sh
sudo bash /tmp/sxmo-default on      # SXMO: sxmo.service вкл., greetd и phosh.service выкл. (+ drop-in tty-force/chvt 7)
sudo bash /tmp/sxmo-default off     # Phosh (как в Mobian по умолчанию)
sudo bash /tmp/sxmo-default status
```
Просто `enable sxmo` не работает: `sxmo.service`, `greetd` и отдельный `phosh.service` все занимают VT7, а на загрузке нужны ещё `tty-force` и `chvt 7` (подробности — STATE.md, п. 49). Если экран пустой или login: по SSH (Wi‑Fi или USB 10.66.0.1) `sudo bash /tmp/sxmo-default off && sudo reboot`.
После `restart sxmo` пользовательские службы остаются от старой сессии → `systemctl --user restart sxmo_desktop_widget sxmo_wob sxmo_hook_lisgd …` (это делает `sxmo-setup`).

## Кнопки (схема «три кнопки», хуки `oneplus,enchilada` из пакета)

Экран **разблокирован**:

| Нажатие | Действие |
|---|---|
| Питание ×1 | цикл состояний: разблокировано → экран выкл → блокировка → разблокировано |
| Питание ×2 | пропустить два состояния (`lock_screen_action 2`) |
| Питание ×3 | открыть терминал |
| Громкость + ×1 / ×2 / ×3 | меню приложений / системное меню / меню окон |
| Громкость − ×1 / ×2 / ×3 | экранная клавиатура вкл/выкл / сменить раскладку окон / закрыть окно |

Экран **заблокирован или выключен**: питание ×1 — следующее состояние (разбудить → разблокировать), ×2–×3 — сразу через два;
громкость ± ×1/×2/×3 меняет громкость на 5/10/15.
В **меню**: громкость +/− листает пункты, питание подтверждает выбор.

## Жесты (`lisgd`, нужен `/dev/input/touchscreen`, его создаёт udev-правило SXMO)

| Жест | Действие |
|---|---|
| от верхнего края вниз / вверх | меню приложений / закрыть меню и убрать уведомления |
| от левого края вверх / вниз | громкость + / − |
| от верхнего края слева / справа (боковой свайп) | яркость − / + |
| от нижнего края вверх / вниз | открыть / закрыть клавиатуру |
| от правого края влево / от левого вправо | предыдущее / следующее рабочее пространство |
| уголок сверху слева / справа | системное меню / меню скриптов |
| уголок снизу слева / справа | блокировка (или экран выкл, если окон нет) / повернуть экран |

Точные имена жестов и действия — в `/usr/share/sxmo/default_hooks/oneplus,enchilada/sxmo_hook_inputhandler.sh` (раздел для разблокированного состояния).

## Что подкручивать

- **Вырез / углы / часы**: `bar notch` (режим `overlay`, высота 28 логических px, цвет `#323232`) заливает зону челки и скруглений и показывает
  часы справа (`/usr/local/bin/sxmo-notch-clock`); основной бар лежит под ним (`gaps 28 0 0 0`) и тянет статус через `/usr/local/bin/sxmo-status-padded`.
  Отступ текста от скруглённых углов задают неразрывные пробелы справа, `NBSP_PAD` в этих двух скриптах (часы 3, основной бар 2); `status_edge_padding` в этой сборке swaybar не работает.
  Высота полосы: `NOTCH_H=32 scripts/sxmo-setup`. В `status_command` нельзя `;` (sway режет строку) — только отдельные скрипты.
- **Поворот экрана** (жест: угол снизу справа, или `sxmo_rotate.sh`): хук `sxmo_hook_rotate.sh` при повороте прячет верхнюю полосу `notch`, поднимает основной бар в самый верх,
  оставляет поле 28 со стороны челки (`right`: слева, `left`: справа, `invert`: снизу) и переносит часы в основной бар; при возврате в портрет всё восстанавливается.
  **При старте — альбомная ориентация** (`exec sh -c "sleep 4; sxmo_rotate.sh rotright"` в `~/.config/sxmo/sway`, STATE п.126; отключить — закомментировать).
  Автоповорота нет (датчиков нет). Жесты по краям в альбомной ориентации не повёрнуты (`lisgd` читает сырые события).
- **Индикатор блокировки**: кружок слева в верхней полосе (белый — разблокировано, красный — `lock`/`screenoff`); в альбоме — в основном баре перед значками.
  Ширина блока с кружком — `CIRCLE_MIN_WIDTH` (285, логические px) в `/usr/local/bin/sxmo-notch-clock`: если кружок уехал, подгонять (ширина бара 360 минус часы с отступом).
  Кружка 󰅶 — включён режим «экран не гаснет» (`screen-awake`). Перечёркнутое «zZ» 󰒳 — `phone-nosleep on` (мьютекс `ssh-work`). Монитор с сетевым штекером 󰢩 (вместо штатной буквы `S`) — не блокировка: открыта SSH/Mosh-сессия (`lockedby`, удерживает от сна; SXMO перепроверяет раз в минуту); `H` hotspot, `M` модем, `N` suspend выключен вручную; `*` мелькает на секунды — служебные мьютексы (мигание LED при смене состояния, ежеминутная проверка мьютексов).
- **Размер интерфейса**: `SXMO_SWAY_SCALE` в профиле (апстрим pmOS — 3; у `enchilada` 2).
- **Таймауты экрана/сна**: `swayidle` SXMO (первая ступень 8 с простоя, потом блокировка/экран/сон). Хуки `sxmo_hook_screenoff.sh`,
  `sxmo_hook_lock.sh`. Чтобы не гасить: `touch ~/.cache/sxmo/sxmo.noidle` и/или `sxmo.nosuspend`; удобнее — пункт Scripts «Экран: не гасить вкл/выкл» (`screen-awake`, значок кружки 󰅶 в баре, STATE п.136).
- **Иконки**: по умолчанию в Mobian — цветные эмодзи. Как в pmOS (глифы Nerd Font): `scripts/sxmo-icons` (с Мака, по USB). Откат: `rm ~/.config/sxmo/hooks/sxmo_hook_icons.sh` и `sudo systemctl restart sxmo`.

## Известные ограничения

- Звонки/SMS не проверить: нет SIM (модем в `sim-missing`). В статус-баре вместо слова `failed` показывается значок модема с крестиком (пользовательская копия `sxmo_hook_statusbar.sh`, `scripts/sxmo-setup` шаг 2b); с SIM появится уровень сигнала.
- Светодиодов-индикаторов нет (`LED does not exist` в логе — норма, `SXMO_DISABLE_LEDS=1`).
- Хуки SXMO 1.18 (pmOS) в Mobian не используются: API разошёлся; взят только профиль устройства.
- Экран включался только со 2-го нажатия питания: на Poco F1 первая команда включения дисплея после выключения «проваливается» (I2C тача `-5`); исправлено обёрткой `~/.config/sxmo/hooks/sxmo_wm.sh` (повтор включения, `scripts/sxmo-setup` шаг 3e).
- Скриншот: `WAYLAND_DISPLAY=wayland-1 grim /tmp/s.png` на телефоне (PNG; JPEG в этой сборке отключён; при выключенном экране снять нельзя, `no supported format found`). Область: `grim -g "x,y WxH"` в логических пикселях (экран 360×748).
- Красная плашка «S»/«LOCK» в статус-баре — состояние SXMO (не `unlock`); короткое нажатие питания переключает.
- `foot`: в конфиге SXMO 1.12 секция `[colors]` → `[colors-dark]` (исправляет `sxmo-setup`, шаг 2c).

## Пункт меню «pmi8998» (Scripts)

Возвращает Type-C/VBUS PMI8998 (автоопределение роли USB, питание хаба) после `apt upgrade`, если тот вернул штатные dtb/регулятор. Показывает статус; при расхождении применяет (~25 с) и просит перезагрузить. Если версия пакета ядра изменилась — пишет «REBUILD» (пересборка на Маке: `scripts/pmi8998-build`, `scripts/pmi8998-install`). Подробности: STATE п.92–93.
