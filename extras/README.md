# extras — необязательное, не входит в образ skladenOS

Всё здесь **не ставится в базовый образ**: подключается по желанию скриптами из репо.
Базовая система (SXMO, звук, зарядка, USB, питание, обои) — в `scripts/` и `RESTORE.md`.

| Каталог | Что | Как поставить |
|---|---|---|
| [`emulators/`](emulators/README.md) | HP Jornada 720 (QEMU), Psion 5mx (WindEmu), PumpkinOS (Palm OS) + пункты меню Scripts | `extras/emulators/install` |
| `misc/sunvox` | пункт меню для SunVox (бинарник SunVox скачивается отдельно, не из репо) | см. заголовок файла |

Общее правило: скрипты запускаются **с Мака** при подключённом по USB телефоне (`PHONE_HOST` по умолчанию `10.66.0.1`)
и сами заливают всё на телефон по SSH (`scripts/phone-ssh`). Своих ROM и чужих бинарников в репо нет.
