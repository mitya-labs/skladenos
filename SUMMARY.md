2. Маска `rmtfs-dir.service` (иначе два `rmtfs` → модем падает → нет Wi-Fi).
3. SLPI не запускать (краш-цикл жжёт батарею); `slpi.mbn` лежит в `/root/fw-disabled/`.
4. Не пробрасывать телефон в UTM при `fastboot flash` (обрыв `usb_read failed e00002eb`).
5. Не использовать `flash_all*.sh` из MIUI (стирает/блокирует); только `scripts/miui-firmware-flash`.
